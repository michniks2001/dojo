# Dojo Martial Artist Platform

The first ever centralized martial artist platform built by and for martial artists!

Built using Next.js for the frontend, Django REST Framework for the backend, and Supabase for the database.

## Main Features

- Post sharing

  - Share news, tips and technique all in one place

- Gym/Event finder

  - Find gyms and upcoming events in your area
  - Easily register for different types of events

- Sparring requests

  - Find new sparring partners in your area
  - Easily organize sparring sessions

- Easily market your gym
  - Spread the word on your gym and events with the touch of a button
